# Vehicle Maintenance Tracking System (VMTS)

Hey! This is my project for **CIS 344 (Fall 2026)** at Lehman College, taught by Professor Yanilda Peralta Ramos. Using in class information, outside help and some ai to streamline a lot of the process this web application was someway able to be comprosed. Whcih serves the purpose of keeping track of vehicle repairs, maintenance history, and trusted mechanics a lot easier.

## What Wad Used
* **Front-End:** HTML, CSS, and JavaScript (for the layout and quick form checks)
* **Back-End:** PHP for handling forms and backend logic
* **Database:** MySQL (using XAMPP locally) with SQL joins to pull all of my tables together

## Cool Features
* **Vehicle Management:** Add and view your cars, trucks, mileage, and VINs.
* **Service Logs:** Keep track of what repairs were done, how much they cost, and when they happened.
* **Mechanics Directory:** Save info on your favorite shops or mechanics (or mark work as DIY).
* **Maintenance Schedules:** Keep an eye on upcoming service tasks.
* **Secure & Relational:** Built using PHP PDO prepared statements to keep things secure, plus SQL joins to connect vehicles, mechanics, and service records smoothly.
